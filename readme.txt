Conditional localization operations owner for Sabri Social Homeopathy Platform.

== Description ==
Provides locale/resource registries, translation workflows, qualified review, terminology, translation memory, controlled MT drafts, linguistic QA and signed locale-bundle release/rollback. Runtime is disabled by default and activation is gated.

== Installation ==
Install only on controlled staging. Configure platform contracts, encryption/signing keys and operational roles before enabling runtime.
