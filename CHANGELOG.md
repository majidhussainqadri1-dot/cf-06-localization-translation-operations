# Changelog

## 0.1.0 — Foundation candidate

- Initialized the conditional WordPress plugin with a safe-default disabled runtime.
- Added locale registry schema and English (United States), Urdu (Pakistan), and planned Arabic seeds.
- Added BCP 47-style locale canonicalization and cycle-safe fallback validation.
- Added stable translatable-resource catalog with source hashing and version increments.
- Added exact named-placeholder validation, risk/data classification, and privacy-minimized audit evidence.
- Added versioned REST endpoints and a truthful administrator status page.
- Added PHP 8.1/8.3 CI, unit tests, secret-pattern guard, and deterministic candidate packaging.

This release does not yet implement translation projects, assignments, terminology, translation memory, linguistic QA, locale bundles, MT/TMS adapters, or production activation.
