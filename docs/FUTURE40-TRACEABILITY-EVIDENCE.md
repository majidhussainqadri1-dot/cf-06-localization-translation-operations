## Common exact-package evidence

The release builder refuses an unbound `SOURCE-CANDIDATE` build, records the exact 40-character source commit in the manifest and SBOM, verifies every archived source file against manifest byte count/SHA-256, emits SHA256SUMS and is rebuilt deterministically in CI. This proves package/source parity only for the exact successful commit; it does not prove staging/live parity.

## Common activation evidence still required

Every Future40 row remains `activation_ready=false` until Founder change-control, privacy/security/domain review, companion contract parity, real staging acceptance, rollback/restore rehearsal and live deployment verification are separately evidenced. Those states must never be inferred from this document or from green CI.
